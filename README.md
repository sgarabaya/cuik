# Cuik Foods

Este es un proyecto para la materia Programacion Avanzada

## Objetivo

El proyecto va a presentar un sistema de gestion para restaurantes que permita organizar el menu de forma online, permita al usuario hacer el pedido desde la mesa y gestione el pago en si; permitiendo dividir los gastos de forma inteligente y facil.

## Componentes generales:

En lineas generales, los componentes del proyecto seran:

- Del lado del "management" del restaurante:
    - Una ABM para gestionar el menu, con precios e informacion extra (alergenos, etc)
    - Una ABM para gestionar mesas, con capacidad maxima de personas
    - Una pantalla para gestionar mesas, asignar mozo y ver pedidos pendientes, estado de pago, etc

- Del lado del cliente:
    - Escanear el QR
    - Elegir de un menu los items a consumir
    - Elegir que items uno consumio ( o decidir por que va a pagar )
    - Elegir % de propina
    - Pagar
